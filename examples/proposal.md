# Research proposal: better retrieval for internal engineering questions

Build a retrieval assistant over engineering documents, incident reviews and code
comments. The proposed contribution is a reranker trained on synthetic questions
generated from our documents. We hypothesize it will improve answer correctness
by 15 percentage points over our existing hybrid keyword/vector baseline.

We have 10,000 documents, a single 24 GB GPU, two engineers and six weeks. We will
evaluate on 200 questions generated by the same model that creates training
questions. The planned metric is an LLM judge's correctness rating.

We assume synthetic questions represent real user needs, that the reranker can
generalize to new documents, and that serving latency will stay below two seconds.
We have no human-labeled test set or access-control evaluation yet.
